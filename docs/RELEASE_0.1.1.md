# 0.1.1 — Pre-release

Released September 15, 2026.

- Added separate pre-release packages for Apple Silicon macOS and glibc Linux x64.
- Set the minimum VS Code version to 1.137.0.
- Updated installation guidance and the example screenshot.
- Retained Windows compatibility work and CI without enabling Windows support.

This historical pre-release is available from [GitHub Releases](https://github.com/achenachena/dockerignore-inspector/releases/tag/v0.1.1). It supports trusted local workspaces only. Windows, WSL, Remote SSH, Dev Containers, and Web were not enabled.

See [validation records](VALIDATION.md) for the original package checks and [the 0.1.1 audit](QA_0.1.1.md) for issues found after release. The queued-update cancellation issue was subsequently fixed in 0.2.0.
