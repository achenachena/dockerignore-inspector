# Contributing

Use English for documentation, code comments, UI text, errors, tests, and release material.

Start with a reproducible user task. Keep the extension local, small, and focused on accurate Docker ignore inspection. Do not add telemetry, AI features, a backend, or automatic project edits.

Run the checks in README before submitting a change. Matching changes need upstream and Docker differential evidence. UI changes need an installed-VSIX check. Report unrun checks honestly.
